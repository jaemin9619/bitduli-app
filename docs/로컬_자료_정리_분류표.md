## 5. 예상 정리 효과와 주의사항

- 두 프로젝트의 `node_modules`, npm 캐시, Functions 의존성, 빌드 캐시만 정리해도 약 859MB를 줄일 수 있음.
- 중복 ZIP, 구버전 복구본, 미사용 이미지, 로그까지 정리하면 총 약 868MB 전후를 줄일 수 있음.
- `bitduli-app/.env`는 삭제 후보가 아니며 최종 ZIP에도 포함되어 있지 않으므로, 삭제 전에 반드시 안전한 별도 보관이 필요함.
- 로컬의 `lineme-diary`를 삭제해도 이미 배포된 Firebase 프로젝트나 클라우드 데이터가 자동 삭제되는 것은 아님.
- 분류표에 따라 실제 이동과 삭제를 완료함. `bitduli-app/.env`와 최종 ZIP은 이동 후에도 재확인함.
- 조건부 항목인 `.claude`와 기능중심 문서 생성 스크립트는 삭제하지 않고 `archive`에 보관함.
